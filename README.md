# harxsan.github.io

Personal site, built natively by GitHub Pages (Jekyll + minima, no local
build step required).

- `_posts/` — blog entries. Permalink: `/:year/:month/:day/:title/`.
- `models/` — the open-model architecture tracker (`/models/`), listing the
  `models` collection (`_models/`).

Every post and every tracker entry goes up as its own PR and is published
only after review — this repo starts as a skeleton with none yet.
